# 📊 Финансовый дашборд ПСК Ньютек — Summary сессии

## Контекст задачи

Владелец (Виталий, @gggvitalii90) предоставил Excel-файл с ~7 971 финансовой транзакцией компании **ПСК Ньютек** за период **январь 2024 – май 2026**. 

Задача: создать интерактивный BI-дашборд с cross-filtering, задеплоить на Beget по домену.

## Что уже сделано ✅

### Дашборд — полностью готов и собран

**Стек:**
- React 18 + Vite 8
- Tailwind CSS 3
- Recharts 3 (основные чарты)
- Apache ECharts 6 + echarts-for-react (3D Pie)
- TanStack Table v8 (детальная таблица)
- Zustand 5 (state management / фильтры)

**Компоненты:**
```
dashboard/
├── src/
│   ├── App.jsx                          ← 4 вкладки + layout
│   ├── components/
│   │   ├── Layout/Header.jsx            ← хедер + кнопка сайдбара
│   │   ├── Filters/FilterPanel.jsx      ← выезжающий сайдбар (translateX 250ms)
│   │   ├── KPI/KPICards.jsx             ← 5 карточек (всегда видны)
│   │   ├── Charts/
│   │   │   ├── CashFlowChart.jsx        ← Bar+Line по месяцам (Recharts)
│   │   │   ├── OperationTypePie3D.jsx   ← 3D Pie: Расход/Приход/Конвертация (ECharts)
│   │   │   ├── BankPie3D.jsx            ← 3D Pie: Банки + Наличный расчёт (ECharts)
│   │   │   ├── ProjectsTab.jsx          ← вкладка Проекты
│   │   │   ├── CostsTab.jsx             ← вкладка Затраты
│   │   │   ├── HBarChart.jsx            ← горизонтальный бар (переиспользуется)
│   │   │   └── DonutChart.jsx           ← donut (переиспользуется)
│   │   ├── Pivot/PivotTable.jsx         ← сводная Объект × Квартал
│   │   └── Table/TransactionTable.jsx   ← детальная таблица с поиском
│   ├── store/useFilterStore.js          ← Zustand: глобальные фильтры + cross-filter
│   ├── hooks/useFilteredData.js         ← useMemo: отфильтрованные данные
│   ├── data/transactions.json          ← все 7971 транзакция (embedded)
│   └── utils/formatters.js             ← форматирование чисел/дат
├── dist/                               ← ГОТОВАЯ СБОРКА (можно сразу деплоить)
├── vercel.json                         ← конфиг для Vercel
└── package.json
```

**Вкладки:**
1. **📈 Обзор** — Cash Flow chart + 3D Pie (тип операции) + 3D Pie (банки)
2. **🏗️ Проекты** — Горизонтальные бары (проекты + объекты) + Сводная таблица
3. **💰 Затраты** — Donut (статьи бюджета + тип оплаты) + Бар (ответственные)
4. **🔍 Детали** — Полная таблица с поиском, сортировкой, пагинацией, экспортом CSV

**Фичи:**
- Cross-filtering: клик по чарту → все остальные перефильтровываются
- Выезжающий сайдбар с фильтрами (date range, multi-select)
- Активные фильтры показываются как теги с кнопкой [✕]
- Адаптивный (desktop 1440px + mobile 390px)
- Ссылки на Google Drive в таблице кликабельны
- Наличный расчёт: NaN в поле "Банк" → отображается как "💵 Наличный расчёт"

**Сборка:**
- `dist/` — готова, 5.3 MB (до gzip)
- Проверено в Playwright/Chromium, скрины сделаны, всё работает

## Важные нюансы

1. **NaN в поле Банк** — это наличные операции (2767 записей, 362.6M ₽). Логика: `bank === null → "💵 Наличный расчёт"`. Реализовано в `BankPie3D.jsx` и `useFilteredData.js`.

2. **Сумма итог vs Сумма** — основной показатель для чартов — `Сумма итог` (с НДС-конвертацией). `Сумма` — исходная.

3. **Данные встроены в JS** — `src/data/transactions.json` (3.5 MB JS-чанк). При большом росте данных можно перейти на lazy load / API.

4. **Vercel MCP** — в прошлой сессии был доступен (`mcp__63ee2931...`), но не работал без токена. Если пользователь подключит Vercel через настройки сессии, сможешь деплоить напрямую.

5. **Версия Node.js у пользователя** — 18.12.1 (устарела). Для `npm run dev/preview` нужна 20.19+ или 22.12+. Для просмотра готового `dist/` достаточно Python.
